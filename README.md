# Бот-помощник для команды учителей

Что умеет:
- **/report** — учитель отправляет отчёт (тема + текст), он сохраняется в Google Таблицу.
- **/faq** — список частых вопросов с кнопками, ответы из Google Таблицы.
- **/addreminder** — ты (админ) добавляешь напоминание на дату/время, бот сам разошлёт его всем пользователям, кто хоть раз написал боту /start.

## Шаг 1. Создать бота в Telegram

1. Открой Telegram, найди **@BotFather**.
2. Напиши `/newbot`, придумай имя и username (должен заканчиваться на `bot`).
3. Скопируй токен вида `123456789:AA...` — это `BOT_TOKEN`.

## Шаг 2. Узнать свой chat_id

1. Напиши боту **@userinfobot** — он пришлёт твой `chat_id`. Это `ADMIN_CHAT_ID`.

## Шаг 3. Подключить Google Таблицу

1. Создай новую таблицу на [sheets.google.com](https://sheets.google.com).
2. Скопируй её ID из адресной строки:
   `https://docs.google.com/spreadsheets/d/ЭТОТ_КУСОК/edit` → это `GOOGLE_SHEET_ID`.
3. Зайди в [Google Cloud Console](https://console.cloud.google.com/):
   - Создай проект (или используй существующий).
   - Включи **Google Sheets API** и **Google Drive API**.
   - Зайди в "IAM и администрирование" → "Сервисные аккаунты" → "Создать сервисный аккаунт".
   - После создания — вкладка "Ключи" → "Добавить ключ" → JSON. Скачается файл — переименуй его в `credentials.json` и положи в папку с ботом.
   - Открой скачанный JSON, найди там `client_email` (что-то вроде `bot@project.iam.gserviceaccount.com`).
4. Открой свою Google Таблицу → кнопка "Настройки доступа" → добавь этот `client_email` с правами **Редактор**.

## Шаг 4. Установить и запустить

```bash
cd teacher_bot
pip install -r requirements.txt
cp .env.example .env
```

Открой `.env` и впиши свои значения `BOT_TOKEN`, `ADMIN_CHAT_ID`, `GOOGLE_SHEET_ID`.
Убедись, что `credentials.json` лежит рядом с `bot.py`.

Запуск:
```bash
python bot.py
```

## Как этим пользоваться

- Учителя пишут боту `/start`, потом `/report`, отвечают на 2 вопроса — отчёт улетает в таблицу.
- Вопросы и ответы для `/faq` ты добавляешь вручную во вкладке **FAQ** таблицы (столбцы "Вопрос" и "Ответ") — бот подхватит их автоматически.
- Чтобы добавить напоминание, напиши боту (от своего аккаунта-админа):
  ```
  /addreminder 2026-10-01 09:00 Сдать отчёт по успеваемости за сентябрь
  ```

## Чтобы бот работал круглосуточно (запуск с iPhone через Railway)

Для теста достаточно `python bot.py` на своём компьютере (пока запущен терминал).
Для постоянной работы, управляя всем с iPhone — используй Railway.app:

1. **Залей эту папку на GitHub.**
   С телефона проще всего через приложение GitHub → "+" → "New repository" →
   загрузить файлы (или через сайт github.com в Safari).
   Файл `.env` заливать **не нужно** — там секреты, они не для GitHub.

2. **Зайди на [railway.app](https://railway.app)** с телефона, зарегистрируйся через GitHub.

3. **New Project → Deploy from GitHub repo** → выбери свой репозиторий.
   Railway сам увидит `requirements.txt` и `Procfile` и поставит всё нужное.

4. **Открой вкладку Variables** проекта и добавь переменные (те же, что в `.env`):
   - `BOT_TOKEN`
   - `ADMIN_CHAT_ID`
   - `GOOGLE_SHEET_ID`
   - `GOOGLE_CREDENTIALS_JSON` — сюда вставь **всё содержимое** файла `credentials.json`
     одной строкой (открой файл, скопируй весь текст целиком, включая `{ }`, и вставь как значение).

5. Нажми **Deploy** (или он задеплоится сам после сохранения переменных).
   В логах проекта должна появиться строка "Бот запущен...".

Готово — бот работает 24/7 в облаке, ты просто переписываешься с ним в Telegram на iPhone,
а при необходимости заходишь на railway.app посмотреть логи или поменять переменные.
